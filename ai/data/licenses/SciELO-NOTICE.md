# Artigos SciELO (CC BY)

Artigos em português do SciELO Brasil, baixados com `ai/scripts/fetch_scielo.py`
pela API ArticleMeta. Cada licença foi conferida na página do artigo.
Uso: anotação automática de checklist e dados de treino (requisito e parágrafo).
O texto integral não é redistribuído pelo repositório. Os rótulos são locais,
feitos por duas anotações de IA independentes segundo `ai/annotation/criterios-v1.md`,
sem revisão humana.

Termos: https://creativecommons.org/licenses/by/4.0/ (ou a versão indicada).
Atribuição: autores e periódico de cada artigo, conforme o DOI.
